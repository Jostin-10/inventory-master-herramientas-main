# Informe de Integración Frontend con Stitch AI

## Introducción

Para el desarrollo de la interfaz de usuario del sistema **Inventory Master**, se utilizó **Stitch AI** como herramienta de diseño asistido por inteligencia artificial. Mediante prompts específicos se generaron prototipos modernos que sirvieron como referencia para la implementación del frontend utilizando React y TypeScript.

---

# Prompts Utilizados en Stitch AI

## Prompt 1 – Página de Inicio

**Objetivo:** Diseñar una página principal atractiva para presentar el sistema y sus funcionalidades.

**Prompt utilizado:**

Diseña una página de inicio moderna para un sistema de gestión de inventario llamado **"Inventory Master"**. Toda la interfaz debe estar en español. Incluye encabezado corporativo, menú de navegación, sección principal con imagen destacada, descripción general del sistema, beneficios principales, categorías de herramientas, estadísticas empresariales, llamada a la acción y pie de página. Utiliza una paleta de colores azul, blanco y gris, manteniendo una apariencia profesional, elegante, moderna y adaptable a dispositivos móviles.

---

## Prompt 2 – Panel de Control Administrativo

**Objetivo:** Crear un dashboard central para la administración del sistema.

**Prompt utilizado:**

Diseña un panel de control administrativo para **Inventory Master**. Toda la interfaz debe estar en español. Incluye menú lateral de navegación, indicadores de productos, categorías, clientes y ventas, gráficos estadísticos, actividad reciente del sistema, resumen general del inventario y métricas clave del negocio. Utiliza un diseño moderno tipo dashboard empresarial con tarjetas informativas, visualización clara de datos y excelente experiencia de usuario.

---

## Prompt 3 – Pantalla de Inicio de Sesión

**Objetivo:** Diseñar la interfaz de autenticación de usuarios.

**Prompt utilizado:**

Diseña una pantalla de inicio de sesión para **Inventory Master**. Toda la interfaz debe estar en español. Incluye campos para correo electrónico y contraseña, opción para recordar sesión, botón de ingreso, mensajes de validación y diseño profesional alineado con la identidad visual corporativa del sistema. Utiliza colores institucionales y una distribución limpia y moderna.

---

## Prompt 4 – Gestión de Productos

**Objetivo:** Diseñar la vista principal para la administración del inventario.

**Prompt utilizado:**

Diseña una pantalla de gestión de productos para un sistema de inventario. Toda la interfaz debe estar en español. Incluye buscador avanzado, filtros por categoría, tabla de productos, stock disponible, precio unitario, categoría asignada, acciones para editar y eliminar registros, además de un botón destacado para agregar nuevos productos. Mantén un diseño corporativo moderno, organizado y fácil de utilizar.

---

## Prompt 5 – Formulario de Registro y Edición de Productos

**Objetivo:** Crear una interfaz para registrar y actualizar productos.

**Prompt utilizado:**

Diseña un formulario para registrar y editar productos. Toda la interfaz debe estar en español. Incluye nombre del producto, categoría, precio, stock disponible, descripción detallada, imagen referencial, botón para guardar cambios y botón para cancelar. Mantén la coherencia visual con el resto del sistema utilizando una apariencia profesional y enfocada en la productividad.

---

## Prompt 6 – Gestión de Categorías

**Objetivo:** Diseñar la administración de categorías de herramientas.

**Prompt utilizado:**

Diseña una pantalla de administración de categorías para **Inventory Master**. Toda la interfaz debe estar en español. Incluye listado de categorías, buscador, estadísticas generales, acciones para agregar, editar y eliminar categorías, indicadores visuales y diseño consistente con el panel administrativo principal. Prioriza la claridad visual y la facilidad de gestión.

---

# Implementación

Los diseños generados mediante Stitch AI fueron utilizados como referencia para desarrollar las vistas funcionales del sistema utilizando:

* React
* TypeScript
* Vite
* Axios
* React Router
* Node.js
* PostgreSQL
* Docker
